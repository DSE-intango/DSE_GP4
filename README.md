# INTANGO DSE Cohort 2 — Git and GitHub starter
Trainer: **Fidèle NDAYISHIMIYE**

A working JavaScript diagnostic correction used as the starting point for hands-on version-control training. No external npm dependencies, no API keys and no installation step are required.

## Start here
1. Extract the ZIP, open this folder in VS Code and open its terminal.
2. Use Node.js 24 (or a compatible Node.js version supporting node:test and ES modules), npm and Git.
3. Run:
```sh
npm start
npm test
```
4. Read docs/CORRECTION.md, then follow docs/GIT_LABS.md.

Do not run npm install just to use this project: it has no dependencies. This archive deliberately excludes .git so each learner can initialise a new repository. GitHub access is needed only for remote/collaboration exercises.
