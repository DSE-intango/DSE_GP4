# Trainer guide
INTANGO TSS — DSE Cohort 2
Trainer: Fidèle NDAYISHIMIYE

## Two periods of 50 minutes
| Minutes | Activity | Evidence |
| --- | --- | --- |
| 0–10 | Run corrected programme; explain array loop and validation | Learner explains expected report |
| 10–25 | Lab 1: init, identity, stage and initial commit | Clean status and first commit |
| 25–40 | Lab 2: edit, diff, staged diff and focused commit | Learner distinguishes three areas |
| 40–50 | Lab 3: feature branch and merge | Branch graph |
| 50–70 | Lab 4: intentional same-line conflict | Correct merged sentence, no markers |
| 70–85 | Lab 7: GitHub remote and push | Repository with committed files |
| 85–95 | Demonstrate PR and Actions; learners start their issue | PR or issue URL |
| 95–100 | Exit check: explain commit, branch, push and conflict | Short oral demonstration |

Continue labs 5, 6, 8–10 in later sessions. If connectivity is poor, finish local labs and postpone GitHub operations; do not rush conflict resolution.

## Suggested version-control rubric (100)
- Staging and focused commits: 20
- Branch/merge and history explanation: 15
- Conflict resolution with explanation: 20
- Safe recovery (unstage, restore, revert): 15
- Issue, PR and peer review: 20
- Passing tests, tag and learning log: 10

The solution is included intentionally for version-control teaching. If reusing the programming diagnostic as a closed assessment, distribute that assessment separately before sharing this project.

## Extension tasks with acceptance criteria
1. Add a valid passMark-75 demo; all existing tests remain green.
2. Add a test proving [49,50,51] counts two passes at 50.
3. Add a CLI summary printer as a new module without changing analyseMarks's eleven-field contract; include a test.
4. Improve documentation through an issue and reviewed PR.
5. Demonstrate a failing test in an isolated branch, explain CI failure, then fix it before merge.

All marks are fictional. Nothing here publishes to GitHub automatically; learners create their own repository and authenticate themselves.
